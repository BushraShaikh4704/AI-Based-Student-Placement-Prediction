# 🎓 AI-Based Student Placement Prediction and Career Recommendation System

**AI-Based Student Placement Prediction and Career Recommendation System** project predicts whether a student is likely to get placed using Machine Learning. It considers **academic performance, technical skills, internships, projects, certifications, aptitude scores, and other factors*. Based on the prediction, the system also recommends skills and certifications to improve placement chances.
